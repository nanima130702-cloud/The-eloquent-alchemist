# 口八丁の錬金術師

声で生き物を錬成して戦う、1対1のターン制ブラウザゲームです。
視覚障がいのある方々も、そうでない方々も、同じ遊びをともに楽しめることをコンセプトにしています。

## 動作環境
- パソコン（Windows / macOS）のブラウザ：Google Chrome または Microsoft Edge の最新版を推奨
- インターネット接続（HTTPS）、スピーカーまたはヘッドホン、マイク（声での操作に使用）
- スマートフォン・タブレットは未対応です
- スクリーンリーダーなどのソフトのインストールは不要です（ブラウザの音声合成・音声認識を使用）

## 起動手順
1. GitHub Pages の公開URL【ここにURLを記入】をブラウザで開く、または同梱のHTMLファイルをブラウザで直接開くことでも起動可能
2. 画面に「どのキーでも、どこをクリックしても、はじまります」と表示される。いずれかを操作すると音声案内が始まる
3. マイクの許可を求める画面が出たら「許可」を選ぶ（キーボードではタブキーとエンターキーを選択可能）
4. 音声案内に従い、はじめる／図鑑／チュートリアルを選ぶ

※ index.html をそのまま公開用リポジトリに置くだけで動作します（外部ファイルは不要）。

## 操作一覧（音声・キーボード・クリックのどれでも同じ操作ができます）
| 場面 | キーボード | クリック | 声 |
|---|---|---|---|
| タイトル | 1：はじめる／2：図鑑／3：チュートリアル／Z：拡大／R：もう一度聞く | ボタン | 「はじめる」「図鑑」「チュートリアル」「拡大」 |
| 図鑑 | →：次／←：前／R：もう一度／S：自動送りの停止・再開／Esc：閉じる | ボタン | 「つぎ」「まえ」「もう一度」「とめる」「とじる」 |
| 錬成（声の抑揚） | スペース：開始・終了 | 画面の任意の場所：開始 | マイクに向かって話す |
| 行動 | A：攻撃／D：防御／S：特殊 | 左：攻撃／中：防御／右：特殊（どこをクリックしても可） | 「こうげき」「ぼうぎょ」「とくしゅ」 |
| バトル中 | H：体力・気力を聞く／R：もう一度聞く | | 「じょうきょう」 |
| 終了後 | Enter：もう一度／T：タイトル | ボタン | 「もう一度」「タイトル」 |

## アクセシビリティ確認表
- [ ] 起動直後、任意のキー／クリックで音声案内が始まる
- [ ] マイク許可の案内が音声で流れる。拒否した場合も、キーボードとクリックで遊べる旨が流れる
- [ ] タイトル・図鑑・バトルが、キーボードのみで操作できる
- [ ] 図鑑が自動で読み上げられ、声の抑揚による「型」の解説が含まれる
- [ ] 攻撃・防御・特殊能力の結果が、音声と効果音で伝わる
- [ ] 選択肢が、枠線と色の両方ではっきり区別できる（Zキーで拡大表示）
- [ ] チュートリアルで、ルールと操作方法を音声で確認できる

## 素材と権利・AIの活用【提出前に必ず確認】
- 効果音：ブラウザのWeb Audio機能でプログラムから生成した独自の音です。外部の音声素材は使用していません。
- キャラクターのデザイン：既存の作品を模さないよう配慮しました。「キャベト魔ト」は、チームオリジナルの制作で、どの資料も参考にしていません。
- 生成AIの活用範囲：アイデアの実体化（仕様をブラウザ上で動作させるためのコーディングやデザイン、UI実装のサポート）に、生成AIを活用しました。
- ドット絵の作成者・作成方法の詳細：「キャベト魔ト」のドット絵のみ、https://pixnote.net/ にて制作しました。

## 注意
- 声の抑揚は、マイクで測定した音声の大きさ・高さ・変化から計算しており、音声データは保存・送信していません。
- 音声認識（声での操作）は、ブラウザの機能を使います。ブラウザによっては外部の音声認識サービスと通信する場合があります。
